How it works

Ask once. Watch it prove its work.

  1. 1

    Type a mission

    Plain language in the sidebar console. The router classifies it and builds a bounded, durable plan — no capability toggles to babysit.

  2. 2

    The agent works, you steer

    Tools run against your real vault, sandbox, and integrations. Consequential steps wait behind approvals; a steering panel adjusts the run live.

  3. 3

    Receipts, not vibes

    Every write lands with a verified receipt, and the mission ends with an acceptance check — pass or fail, with reasons you can read.

Designed for trust

Agentic where useful.
Explicit where consequential.

Native and local-first

The assistant lives in Obsidian's right sidebar and works through vault-relative paths and Obsidian APIs. Your notes never become someone else's database.

Append first

Ordinary writing appends safely. Replacement and destructive actions require explicit intent, a backup, or an approval.

Visible proof

Run Details keeps plans, tool activity, validation, and write receipts inspectable without crowding the chat.

Minimal setup

One working mode and connection-derived readiness replace a wall of independent capability toggles. BYOK: your Ollama Cloud key stays in Obsidian SecretStorage.
